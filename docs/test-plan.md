## 2. 接口测试（REST API）

| 编号 | 接口 | 用例 | 预期 |
|---|---|---|---|
| A-01 | POST /api/auth/register | 非法邮箱 / 短密码 | 400 + 明确错误 |
| A-02 | POST /api/auth/login | 错误密码 | 401 统一提示 |
| A-03 | GET /api/trips | 未登录 | 401 未登录 |
| A-04 | POST /api/trips | 结束日期 < 开始日期 | 400 "结束日期不能早于开始日期" |
| A-05 | POST /api/days/:id/locations | 纬度越界 / 类型非法 | 400 明确错误 |
| A-06 | POST /api/trips/:id/expenses | 金额 ≤ 0 | 400 "金额必须大于 0" |
| A-07 | PUT /api/expenses/:id | 部分字段编辑 | 仅更新提交字段，其余保留 |
| A-08 | DELETE /api/trips/:id | 删除 | 200，级联数据清理 |
| A-09 | POST /api/upload | 非图片类型 / 超 5MB | 400 拦截 |
| A-10 | POST /api/trips/:id/expenses | 地点属于其他旅行 | 400 "地点不存在或不属于该旅行" |
| A-11 | POST /api/trips/:id/expenses | 地点属于该旅行但非所选旅行日 | 400 "所选地点不属于该旅行日" |
| A-12 | POST /api/trips/:id/expenses | 只给地点不给旅行日 | 自动继承地点所属旅行日 |
| A-13 | POST /api/trips | 非法状态值 | 400 "旅行状态不合法" |
