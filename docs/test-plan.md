## 8. 性能测试

> 验证脚本：`scripts/test-performance.cjs`；环境：生产模式（`npm run start`），本机 localhost；
> 数据规模：50 地点 / 100 游记 / 500 图片 / 500 笔消费（脚本：`scripts/perf-seed.sql`，旅行 ID=30）。
> 每页 3 次请求取中位耗时（本地生产模式参考值，非公网基准）。

| 页面 | 中位耗时 | 最快 | 最慢 | 响应大小 |
|---|---|---|---|---|
| 首页 `/` | 52.6 ms | 50.1 ms | 255.4 ms | 35 KB |
| 旅行详情 `/trips/30` | 51.7 ms | 37.8 ms | 147.2 ms | 36 KB |
| 分析中心 `/analytics` | 42.6 ms | 38.7 ms | 69.0 ms | 17 KB |
| 旅行回顾 `/trips/30/review` | 115.8 ms | 96.9 ms | 163.1 ms | 764 KB |

结论：在 50/100/500/500 数据规模下，主要业务页面（含回顾页 500+ 图片 URL 与地图轨迹聚合）均可在 120ms 内完成服务端渲染，满足基础性能要求。
